ULTRA-FAST MP STARTUP v0.3.1 - FIXED VERIFIER

WHAT THE v0.3 ERROR WAS
=======================
The original v0.3 installer correctly avoided executable ContextPtr:SetUpdate()
calls, but its final safety checker searched for the literal text:

    ContextPtr:SetUpdate

One of v0.3's comments contained:

    -- Intentionally NO ContextPtr:SetUpdate here.

The checker therefore falsely failed on its own comment.

v0.3.1 changes the checker to match only a real executable Lua line:

    ContextPtr:SetUpdate(...)

Comments no longer trigger the error.

IMPORTANT IF v0.3 ALREADY FAILED AT THE FINAL SAFETY CHECK
==========================================================
The safety check ran AFTER MainMenu.lua, MultiplayerSelect.lua, and Lobby.lua were
patched. Therefore the functional v0.3 patch was probably already installed.

You can simply run the v0.3.1 installer over it. It recognizes the existing v0.3
markers, does not duplicate them, and performs the corrected verification.

No reset is required for this particular error.


LEKMOD 30.7 - ULTRA-FAST MP STARTUP v0.3
REROLL-SAFE BUILD

WHY v0.2 BROKE REHOSTING
========================
MP Reroll/Rehost v0.21 uses ContextPtr:SetUpdate() in:
  MainMenu.lua
  MultiplayerSelect.lua
  Lobby.lua

Ultra-Fast MP Startup v0.2 also installed ContextPtr:SetUpdate() in those same
three UI contexts.

Civ V does not combine SetUpdate callbacks. The later call replaces the earlier one.

Because Ultra-Fast was installed after Reroll/Rehost, v0.2 replaced the update
handlers that v0.21 needed to continue:

  running game
    -> Main Menu
    -> Multiplayer Select
    -> Lobby
    -> host setup
    -> replacement staging room

The result was exactly:
  host presses reroll
    -> exits successfully
    -> reaches Main Menu
    -> stops there

This can happen WITHOUT Really Advanced Setup installed. RAS is not required for
the conflict.

WHAT v0.3 CHANGES
=================
v0.3 removes the old Ultra-Fast v0.2 routing blocks and replaces them with
versions that NEVER call ContextPtr:SetUpdate().

Main Menu:
  Uses Civ V's existing RestoreUI event after DLC/frontend initialization.

Multiplayer Select:
  Uses its normal ShowHide callback and immediately follows stock Standard -> Internet.

Internet Lobby:
  Uses the server-list events generated by RefreshInternetGameList().
  No timer/update callback is needed.

Therefore Reroll/Rehost v0.21 keeps ownership of all update callbacks it needs.

WHAT IT STILL DOES
==================
- Skips/renames the startup Opening_Movie logo media.
- Keeps SkipIntroVideo = 1.
- Skips the LegalScreen popup when possible.
- Normal fresh launch goes directly to Standard Internet multiplayer.
- Best-effort friend-host autojoin remains.
- If no friend-hosted lobby is found on the initial refresh, you remain in the normal
  Internet browser.

INSTALL
=======
CLOSE CIV V.

Run:
  INSTALL_ULTRAFAST_MP_STARTUP_V03_REROLLSAFE.bat

Then:
  VERIFY_ULTRAFAST_MP_STARTUP_V03_REROLLSAFE.bat

The verifier checks:
- Reroll/Rehost v0.21 is still present.
- old UltraFast v0.2 Lua blocks are gone.
- v0.3 blocks are present.
- no v0.3 block owns ContextPtr:SetUpdate().

YOU DO NOT NEED TO UNINSTALL v0.2 FIRST.
v0.3 removes only the old UltraFast v0.2 Lua blocks while preserving Reroll/Rehost
and the rest of the stack.
